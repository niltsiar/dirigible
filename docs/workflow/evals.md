# Eval set of the workflow docs

This file is the regression set of the workflow docs (`AGENTS.md`, `.claude/skills/`, `.claude/agents/`, `docs/principles.md`, and `scripts/`). Each scenario is a question from a real incident or from a sampled rule of the rule register. Reflect rule 8 and the eval-engineering lens use the `Files` column: a change that trims, deletes, merges, or moves a rule in a file of that column runs the scenario again.

## How the eval runs

- A doc set is a copy of the docs at one commit. The old set is `3bc03e0`. The new set is the tip of `chore/workflow-consolidation`. For E11-E18, the old set is main at `5b01f78`, and the new set is the tip of `chore/workflow-speed`. For H14, the old set is main at `b5bdf41`. For E20, the old set is main at `339f1a4`, and the new set is the tip of `docs/readable-pr-text` at `9c819dd`. On that new set, H7 passes 3 of 3 (old set 3 of 3), and H13 fails 3 of 3, so it stays void. For H14 and the E6 regrade, the new set is the tip of `chore/verify-copy`. An `Old` or `New` cell with `-` has no grade yet.
- For each set, three fresh agents answer each question, each in a shuffled order. Each agent starts at `AGENTS.md` and `.claude/skills/deliver/SKILL.md`. It opens another file only through a pointer in a file that it already read, and it quotes that pointer.
- Each step of an answer is a verbatim quote and its path. A quote check drops a quote that is not in its file, and a quote from a file that the agent reached with no pointer.
- A blind grader sees the key points and the surviving quotes, with neutral labels that mix the old and the new answers. A scenario passes in a run when a quote holds each key point.
- `retention` means that the old docs can pass the scenario. `policy` means that the old docs fail it by design, because decision 0028 changed the rule.
- The pass rule (run `2026-09-30-workflow-consolidation`, criterion C6): the sum of retention passes of the new set is at least the sum of the old set; after six runs, no scenario of the new set is two or more passes below the old set; each policy scenario passes in at least two of three runs (four of six). A holdout that both sets fail in each run is void.
- E1 key point (c) scores as policy, not retention (decision row of the code gate, D12). The E1 scores below leave out (c). The new set passes E1 (c) in 6 of 6 runs, and the old set in 0 of 6.
- Stall rule: after two fix cycles in which a scenario stays below its pass rule, the next cycle edits no doc for it. It sorts each failed answer by cause (the rule is not in the docs, the answer does not quote it, the key point is out of reach, or the scenario or the grader is wrong) and reports the result.
- The scripts, the answers, the grading packets, and the logs are in `.scratchpads/runs/2026-09-30-workflow-consolidation/eval/`, `answer/`, and `grade/`. That folder is not in git.
